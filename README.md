# 4d-form-tutorial
How to design a form in 4D

## 4D form knowledge has moved

The per-object form documentation previously in `.github/instructions/`
now lives in [miyako/skills](https://github.com/miyako/skills) as the
`4dform` and `4dcli` skills. Install that skillset once and it applies to
any 4D project. See [AGENTS.md](AGENTS.md).

This repository keeps the runnable example project under `example/`.
